# Changelog

## Unreleased

This project is still pre-1.0, so the initial changelog entry tracks the current baseline rather than a tagged release.

### Added

- MCP tools for `search`, `search_many`, `search_and_fetch`, `research`, `fetch_url`, `fetch_many`, and `health`
- `stdio` and `streamable-http` transport support
- rendered fetch support for JavaScript-heavy pages
- hidden raw payloads to keep visible output compact
- benchmark tooling for latency and token-size measurement
- a hardened Docker deployment path
- an MCP-native guide and config resource

### Notes

- breaking changes may still happen before the first tagged release
- release notes should be added here as versions are published
- this page is the source of truth for public release history once tags exist
